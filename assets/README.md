# UI assets

Keep app logos, icons, and other branding images here, at the project root.

- `logo.svg`: window-header logo. Replace it with your own SVG using the
  same filename. The frontend imports this file; rebuild Electron for a packaged change.
- `tray.png`: Windows tray and window icon. Keep a square transparent PNG.
  Restart Electron after replacing it.

These are the only authored branding images. Interface action icons come from
Lucide; colors and materials are set in Appearance. Avatar models, animations,
voice samples, effects, and imported user media keep their existing locations.
Third-party fonts and package assets stay in their dependencies.
