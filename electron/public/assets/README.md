# Interface assets

Place replacement UI artwork here and reference it as `assets/<filename>`.
There is no default decorative logo. All interface glyphs are selected centrally
in `src/ui/icons.jsx`; skin defaults and color presets live in `src/ui/skins.mjs`.
The character name is loaded from YAML, not baked into an image or component.
Character models/reference audio and user effect assets retain their existing
configured directories; the appearance page does not move or delete user assets.
